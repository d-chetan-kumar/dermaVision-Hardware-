5. CAN THE EXISTING 2,489 VALIDATION IMAGES BE RETAINED WITHOUT LEAKAGE?
--------------------------------------------------------------------------------
SCIENTIFIC VERDICT: NO.

Detailed Justification:
1. 1,345 out of the 2,489 validation images (54.04%) belong to lesions that the model
   encountered during training. For BCC and Melanoma, the contamination exceeds 79%.
2. Retaining this exact validation set while attempting to remove overlapping lesions
   from the training set would require deleting 2,882 images (28.95%) from training,
   severely destabilizing training representations and invalidating existing checkpoints.
3. Filtering the validation set to keep only non-overlapping lesions shrinks it from
   2,489 to 1,144 images, with severe class collapse (BCC drops by 85.1% to only 99
   samples, Melanoma drops by 79.3% to only 187 samples).

6. SMALLEST SCIENTIFICALLY VALID ADJUSTMENT PRESERVING 12,445 IMAGES
--------------------------------------------------------------------------------
Proposed Methodology: Stratified Grouped K-Fold (StratifiedGroupKFold)

Procedure:
1. Preserve all 12,445 images and their 3 original classes (BCC: 3,323, MEL: 4,522, NV: 4,600).
2. Assign unified group identifiers:
   - If lesion_id is present, group_id = lesion_id.
   - If lesion_id is missing (1,886 images), group_id = 'unk_' + image_id (treat as unique single-image lesion).
3. Perform a grouped stratified split using StratifiedGroupKFold(n_splits=5, shuffle=True, random_state=42):
   - Training Set:   9,943 images (79.90%)
   - Validation Set: 2,502 images (20.10%)
   - Group Overlap:  EXACTLY ZERO (0) overlapping lesions.
   - Class Distribution in Validation:
     * BCC:      668 images (20.10% of total BCC)
     * Melanoma: 896 images (19.81% of total Melanoma)
     * Nevus:    938 images (20.39% of total Nevus)
This adjustment shifts only 13 images from train to val (2,502 vs. 2,489), perfectly maintains
the 80:20 ratio and class balance, and completely resolves patient/lesion data leakage.

7. STRATEGY FOR RESERVING A GENUINELY INDEPENDENT TEST SET
--------------------------------------------------------------------------------
Challenge in Current Setup:
The curated set exhausts all 3,323 BCC and all 4,522 Melanoma images available in ISIC 2019.
Therefore, an independent 3-class test set cannot be sourced from remaining ISIC 2019 data alone.

Two Scientifically Rigorous Pathways:

Path A: Internal 3-Way Lesion-Grouped Split (70% Train / 15% Val / 15% Test)
- Split the 12,445 curated images into:
  * Training (70%):   ~8,711 images (grouped by lesion_id)
  * Validation (15%): ~1,867 images (for early stopping & ensemble weight tuning)
  * Test Set (15%):   ~1,867 images (strictly locked, evaluated ONCE at publication time)
- Advantage: Self-contained within ISIC 2019, zero lesion leakage.
- Note: Requires retraining from scratch on the 70% training split.

Path B: External Benchmark Generalization Test Set (PAD-UFES-20 / BCN20000 / Fitzpatrick17k)
- Retain the current 12,445 dataset for training and validation.
- Evaluate models on an external dermatological dataset containing confirmed biopsy ground truth
  for BCC, Melanoma, and Nevus (e.g. PAD-UFES-20 smartphone dermoscopy or HAM10000 held-out).
- Advantage: Evaluates real-world domain generalization across cameras, skin tones, and clinics.
